# STRING 12.5：用微调语言模型为蛋白质网络添加调控方向和符号

多年来，当研究人员的单细胞转录组实验发现某个基因上调时，最关键的一个问题往往被忽视了：是谁在调控它？是哪个转录因子、哪条信号通路？现有的蛋白质相互作用数据库（如STRING）可以告诉你哪些蛋白质功能相关，但通常无法回答"谁调谁"这个方向性的问题。STRING数据库22年来一直采用无向网络的设计，这对大规模聚合多源证据很有效，但在调控方向性和具体交互类型上留下了空白。STRING 12.5的目标是填补这个信息瓶颈，它通过微调的语言模型自动从12亿条科学文献句子对中提取有向调控关系，并为系统生物学工作流提供可信的、带方向的、多粒度的蛋白质调控图谱。

## 背景

系统生物学研究长期面临一个规模上的困境。关于蛋白质如何相互调控的知识大量存在于科学文献中，但手工提取这些信息在出版规模面前几乎是不可行的。同时，现有的几种常见方法都有明显的局限性。完全手工策展的数据库（如SIGNOR和BioGRID）精度高，但规模小、覆盖不足、且往往偏向于研究充分的生物体和通路。仅基于序列同源性或三维结构预测的方法（如AlphaFold）只能告诉你两个蛋白质是否可能结合，看不到调控环境、看不到激活还是抑制、看不到功能必要性。无向的共表达网络可以识别蛋白质间的功能关联，但这种"相关"远非"因果"——当两个蛋白质共同上调时，可能是因为两者都被第三个调控因子激活，而不是彼此调控。

早期的文本挖掘方法（关键词共现、简单依存分析）容易漏掉复杂的调控表述、否定和上下文，也难以区分不同的交互类型和方向。即使有了蛋白质的向量表示（基于序列或网络），这些嵌入也往往只存在于研究论文或临时的机器学习流程中，很少被集成到公共数据库，迫使从业者不得不重复计算或放弃跨物种比较。STRING 12.5正是为了突破这些限制而设计的。

## 核心 idea

核心创新是利用微调的RoBERTa语言模型自动识别和分类有向调控关系，而不依赖人工策展。作者在RegulaTome语料库上微调RoBERTa-large-PM-M3-Voc，该语料库包含16,961个专业标注的调控关系。微调后的模型被应用于来自PubMed和PMC的12亿条句子对，逐句识别八种调控关系类型，包括正调控、负调控、基因表达调控、降解调控和磷酸化等。微调后的RoBERTa模型在RegulaTome测试集上达到了73.5%的F1分数（精准率75.2%，召回率71.8%），从中提取出约43百万条有向调控交互，其中约18百万条涉及人类蛋白质。

这些自动提取的关系随后与来自策展数据库（SIGNOR、KEGG、Reactome）的高置信度关系进行整合。关键的创新在于置信度评分机制，它收集来自文本挖掘、策展数据库、共表达和实验四个独立证据通道的信息，将每个通道的原始度量转换为概率分数，然后使用基于概率独立性假设的"嘈杂或"公式组合这些分数，最终生成0-1之间的调控置信度。这种方法既保留了高质量的手工标注关系，又利用了大规模语言模型的覆盖优势。

![架构示意图](images/page_1_img_1.jpeg)

与此同时，STRING 12.5改进了富集分析的统计方法。传统的方法是对所有数千个基因本体术语进行均匀的多重假设检验，这对小规模查询集会导致统计检验力不足。新方法首先计算给定查询大小和背景下哪些术语大小在理论上可能显示富集，只测试这个"可行窗口"内的术语，然后应用Benjamini-Hochberg FDR修正，再通过Jaccard相似度过滤移除高度重叠的冗余术语，最后按"信号"度量（富集比与-log(FDR)的调和平均值）重新排序结果。

最后，作者利用FedCoder方法对齐不同物种间的网络嵌入。通过node2vec或MCL从STRING网络中提取每个物种的网络嵌入，再学习线性变换矩阵将不同物种嵌入对齐到统一空间，并与ProtT5序列嵌入结合，最终为所有真核生物的蛋白质提供可下载的跨物种联合嵌入。

## 方法

整个工作流包含四个主要步骤。第一步是大规模调控关系提取，使用微调RoBERTa逐句处理所有12亿个句子对。对每个蛋白质对，模型输出多标签预测，因为一个句子可以同时描述多种调控关系（例如某个蛋白既参与磷酸化也参与正调控）。这一步自动识别和分类了八种调控关系类型，从而保留了关系的细粒度信息。

![主要方法流程图](images/page_4_img_1.jpeg)

第二步是多通道证据聚合和置信度评分。对于每条提取的交互，系统从四个独立通道收集信息。设每个通道$i$的原始证据为$e_i$，经过校准后得到概率$p_i \in [0,1]$，综合置信度为：

$$P = 1 - \prod_{i} (1 - p_i)$$

这个"嘈杂或"模型基于概率独立性假设，使得不同通道的证据可以无缝组合，即使来自文本的弱信号与策展数据库中的强信号结合，也能产生合理的综合置信度。

第三步是改进的富集分析。用户提供一个基因集后，系统首先计算理论上可能富集的术语大小范围（根据查询大小、背景和显著性阈值），从而避免对所有术语进行等量检验。这特别有助于小规模查询集的统计检验力。之后应用Benjamini-Hochberg FDR修正、Jaccard相似度过滤和"信号"度量重新排序，大幅减少输出的冗余和混乱。

第四步是跨物种嵌入对齐。从STRING网络中用node2vec或MCL提取每个物种的网络嵌入，然后用FedCoder方法学习一个线性变换矩阵将不同物种嵌入映射到统一空间。最后与ProtT5序列嵌入结合，为所有真核生物蛋白质提供可下载的联合嵌入，使得不同物种的蛋白质可以在同一表示空间中进行比较和预测。

## 实验

实验结果证实了这套方法的有效性和规模。RoBERTa微调模型在RegulaTome测试集上达到了73.5%的F1分数，基于此从12亿句子对中提取出约43百万条有向调控交互。这些交互中，72.9%具有方向性注解，33.1%具有符号注解（正或负调控），约18百万条涉及人类蛋白质。

这些新的有向调控关系已无缝集成到STRING的既有数据结构和可视化中，用户现在可以看到带有方向箭头的调控边、置信度分数和细粒度的关系类型标签。在富集分析的表现上，新的自适应FDR过滤和Jaccard相似度冗余过滤显著改善了结果的可读性和可信度，特别是对于小规模查询集。

关于跨物种蛋白质嵌入对齐，作者已生成了可供所有真核生物蛋白质下载的预计算嵌入。论文声称这增强了跨物种蛋白质预测，特别在亚细胞定位和功能预测任务中表现更好，虽然具体的定量性能指标未在论文中详细公布。

## 局限和未来

尽管工作成果显著，论文也坦诚了几个需要注意的限制。首先，虽然报告了73.5%的F1分数，但完全缺乏与BioBERT、PubMedBERT或GPT-4等其他方法的并排基准对比，无法判断这个精度是否已达到最先进水平。其次，按调规关系类型（如磷酸化vs转录调控）细化的性能指标被隐瞒，对于多标签任务的生产使用来说这是一个重要的缺口。第三，缺少置信度阈值与精准率-召回曲线的对应关系，用户无法准确评估在不同阈值下的假正例率。

第四，一些关键的再现性信息不够明确，包括RegulaTome的训练/验证/测试分割策略、RoBERTa检查点的确切版本、PubMed/PMC语料库的快照日期，以及用于校准的各个策展数据库的版本。第五，跨物种嵌入对齐声称提高了预测性能，但缺少定量结果。第六，论文未讨论失败模式，如非人类蛋白质的覆盖变化、直接vs间接调控的区分能力，或如何处理上下文相关的调控（如仅在神经元中发生）。

## 一句话总结

STRING 12.5通过微调语言模型首次为蛋白质网络的22年演进增添了方向性和细粒度的调控符号，为系统生物学和计算蛋白质组学研究提供了一个宝贵的新工具，但用户依赖这些提取的交互进行关键决策时应该意识到73.5%的F1精度和缺失的细粒度性能评估。
