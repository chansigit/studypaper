# 蛋白质网络终于有了"谁调谁"的答案

当你做单细胞转录组实验，发现某个基因突然上调，第一个问题往往是：谁在调控它？但传统的蛋白质网络只告诉你哪些蛋白质可能相关，却说不清方向和因果。STRING 12.5通过微调语言模型读懂海量文献，终于为这个问题给出了有向答案。

## 问题的根源

系统生物学长期面临一个信息瓶颈：海量科学文献中藏着谁调控谁的知识，但手工整理根本追不上发表速度。

比如一个做单细胞RNA-seq实验的研究生发现某个基因突然上调，接下来的问题就是：谁在调控它？现有蛋白质网络只编码"无向的功能相关性"，无法从因果层面给出答案。

## 旧方法的天花板

手工策展数据库精度高但覆盖小。序列相似性和AlphaFold可以预测蛋白质能否结合，但看不清激活还是抑制。无向的共表达网络最致命的缺陷是无法区分因果：两个蛋白质共表达，可能是因为它们被同一个调控因子同时控制，而不是一个调控另一个。早期的自然语言处理方法太浅，容易遗漏复杂表述和否定语境。

## 核心方案：用语言模型读文献

作者们在16961个标注的调控关系上微调RoBERTa模型，然后将它应用到12亿条PubMed和PMC的句子对。模型学会了识别八种调控关系类型：正调控、负调控、基因表达调控、降解调控、磷酸化等。从这个海量处理中，他们提取出4300万条有向调控交互，其中1800万条涉及人类蛋白质。

![STRING 12.5调控网络提取和整合架构](images/page_1_img_1.jpeg)

## 如何衡量和融合证据

对每条提取的交互，系统从四个证据通道收集信息：文本挖掘、已有的策展数据库、共表达、以及实验验证。每条证据被转化为概率分数，再用一个统计模型组合这些分数，最终产生0到1之间的置信度，让用户可以按需筛选。

同时，富集分析也被改进了。不再对成千上万个生物学术语盲目检验，而是先计算哪些术语大小在统计上可能被富集，只测试这个可行的范围，大幅提升了小查询集的检验力。结果按"信号"指标排序，兼顾富集强度和统计显著性。

## 跨物种对标准答案

作者还用FedCoder方法对齐不同物种的蛋白质表示，让真核生物跨物种的蛋白质可以在同一个表示空间中比较，增强了跨物种的预测性能。

## 成果与局限

73.5%的F1精度在RegulaTome测试集上达成，这些有向关系已无缝集成到STRING的既有工具中。但用户需要知道一个事实：论文没有给出与其他语言模型方法（BioBERT、GPT-4）的并排对比，也没有披露按调控类型细化的性能差异。对于生产级应用，还需要更多的细粒度评估和失败模式分析。
